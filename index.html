Listas

Lista desordenada (ul)

  • CSS es un lenguaje de estilos
  • Se usa para dar diseño a páginas HTML
  • Permite controlar colores, fuentes y layouts

Lista ordenada (ol)

  1. Crear el archivo HTML
  2. Vincular la hoja de estilos CSS
  3. Definir selectores y propiedades
  4. Aplicar estilos a los elementos

Lista de definición

Selector
Indica a qué elemento HTML se le aplicarán los estilos
Propiedad
Característica del elemento que se desea modificar
Box Model
Modelo que describe el espacio que ocupa un elemento
Especificidad
Regla que determina qué estilo se aplica cuando varios selectores apuntan al mismo elemento.
